# Варианты редизайна «Караул»

В `index.html` собраны три мобильных направления:

1. **Оперативный сигнал** — тёмная тема с коралловым акцентом, быстрым считыванием статусов и мягкими карточками.
2. **Светлый штаб** — дневная светлая тема, больше воздуха и спокойнее визуальная иерархия.
3. **Командный контур** — техническая тёмно-синяя тема с янтарным акцентом и высокой плотностью данных.

Каждое направление показывает:

- вход, регистрацию и первый запуск без выбранного караула;
- вкладки «Раскладка», «Статистика», «Сотрудники», «Работа» и «Доступ»;
- выбор сотрудника и очередь резервных водителей;
- статусы отсутствия, вид отпуска и календарь диапазона;
- карточку сотрудника с несколькими отпусками;
- ПТВ с учётом по экземплярам и количеством;
- роли, приглашения и подтверждение удаления;
- предварительный просмотр PNG.

PNG-файлы рядом с HTML предназначены для быстрого сравнения вариантов.
